SMART ATTENDANCE MONITORING SYSTEM — VS CODE STARTER

FILES
- index.html: page structure
- style.css: light, responsive interface styling
- script.js: attendance/session logic and browser storage

HOW TO RUN
1. Extract this ZIP file.
2. Open VS Code.
3. Click File > Open Folder and select the extracted Smart_Attendance_Monitoring_System folder.
4. Open index.html.
5. If you have the Live Server extension, right-click index.html and choose "Open with Live Server".
   Otherwise, double-click index.html in File Explorer to open it in your browser.

FEATURES
- Dashboard overview
- Sample student list from the project report
- Add/remove students (unique roll number check)
- Create course attendance sessions
- Mark each student Present or Absent
- Prevent duplicate entries for the same student in the same session
- Attendance percentage summary
- Export records as CSV
- Data persists in this browser using localStorage

IMPORTANT
This is a front-end educational prototype. Data is stored only in the current browser profile/device. It has no backend, real authentication, database, biometric verification, or cloud sync. The sample student list is preloaded for demonstration. Replace or remove sample records as needed.
